## Comment prendre les screenshots

### Sur macOS
1. Lancez l'application : `npm run dev:all`
2. Ouvrez votre navigateur sur `http://localhost:5173`
3. Pour chaque page :
   - Appuyez sur `Cmd + Shift + 4` puis `Espace` pour capturer la fenêtre
   - Ou utilisez `Cmd + Shift + 3` pour tout l'écran
4. Renommez les fichiers selon les noms ci-dessus
5. Déplacez-les dans ce dossier

### Sur Windows
1. Lancez l'application : `npm run dev:all`
2. Ouvrez votre navigateur sur `http://localhost:5173`
3. Pour chaque page :
   - Appuyez sur `Win + Shift + S` pour Snipping Tool
   - Ou utilisez `Print Screen` pour tout l'écran
4. Renommez les fichiers selon les noms ci-dessus
5. Déplacez-les dans ce dossier

### Sur Linux
1. Lancez l'application : `npm run dev:all`
2. Ouvrez votre navigateur sur `http://localhost:5173`
3. Utilisez `gnome-screenshot` ou votre outil de capture préféré
4. Renommez les fichiers selon les noms ci-dessus
5. Déplacez-les dans ce dossier

## Astuces pour de belles captures

- Utilisez un navigateur en mode plein écran (F11)
- Masquez les barres d'outils du navigateur si possible (mode présentation)
- Assurez-vous que les données affichées sont réalistes et professionnelles
- Évitez les captures avec des erreurs ou des bugs visibles
- Utilisez le thème par défaut (pas de dark mode)
- Vérifiez que tous les textes sont lisibles
